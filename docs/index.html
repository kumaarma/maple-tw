查詢台版角色資料

輸入角色名稱，即可查看等級、裝備、聯盟、HEXA 等資訊。

  1. 輸入角色名並按查詢
  2. 瀏覽上方分頁查看裝備、聯盟等詳細資料
  3. 分頁資料點開才載入，節省 API 配額
逐格比對要顯示

逐格比對兩位角色的裝備：星力、潛能等級、卷軸次數與數值總和。 每位角色需 4 次 API（ocid、基本、能力值、裝備），抓過就留在本次工作階段。

想入手一件裝備但不確定值不值得換？填進那件的數值，直接跟你身上同欄位的比。 角色資料需 4 次 API（ocid、基本、能力值、裝備），與「裝備比對」共用，抓過就不再打。
